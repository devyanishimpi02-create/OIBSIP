# Personal Portfolio Website

A responsive personal portfolio website built as part of the OIBSIP Web Development Internship (Level 1, Task 2).

**Live Demo:** _add your deployed link here once hosted (e.g. GitHub Pages / Netlify / Vercel)_

## 👩‍💻 About

This is a personal portfolio site for **Devyani Narendra Shimpi**, a Computer Engineering student and aspiring software developer / data science enthusiast. It serves as a digital résumé showcasing skills, projects, and contact information.

## ✨ Features

- **Hero section** — name, role, and a monogram-style avatar
- **About Me** — a short bio covering background and interests
- **Skills section** — technical skills grouped into Languages, Runtime & Data, and Tools
- **Projects section** — two real projects, each with a description, tech tags, live demo link, and GitHub link
- **Contact section** — clickable email, LinkedIn, and GitHub links
- **Smooth scroll navigation** — anchor-based navigation between all sections
- **Consistent branding** — a dark, terminal-inspired color and typography system used throughout
- **Fully responsive** — adapts to desktop, tablet, and mobile, including a collapsible mobile nav menu

## 🛠️ Tech Stack

- **HTML5** — semantic page structure
- **CSS3** — custom properties (CSS variables) for theming, Flexbox & Grid for layout, media queries for responsiveness
- **JavaScript (vanilla)** — mobile nav toggle and scroll-based active-link highlighting
- **Google Fonts** — JetBrains Mono (headings/monospace accents) & Sora (body text)

## 📁 Project Structure

```
WebDev-L1-PersonalPortfolio/
├── index.html      # Page structure and content
├── style.css       # Styling, theme variables, responsive layout
├── script.js       # Mobile nav toggle + active nav-link highlighting
└── README.md        # Project documentation
```

## 🚀 Running Locally

No build tools or dependencies required.

1. Clone or download this folder.
2. Open `index.html` directly in any modern browser.

That's it — the site runs entirely client-side.
